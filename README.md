# コマ割り一覧

コマ割りの一覧です。コマ割りを選ぶと、各コマにぴったりの白紙 PNG（コマ下絵）を ZIP でダウンロードできます。描いた絵は、対象のコマをクリックしてアップロードするか、画像ファイルをコマにドラッグすると、コマに表示して並びを確かめられます（画像はこのブラウザの中だけで表示し、どこにも送りません）。

- ページ: https://k-hana.github.io/koma-layouts/
- 白紙の大きさ: ページ幅（既定 2000px）を基準に、各コマの頂点をすべて含む矩形（斜めのコマ・回転も考える）に余白（既定 48px）を足した大きさ。
- ファイル: `index.html`・`app.js`（ビルドなし）・`layouts.json`（コマ割りの一覧）。

`layouts.json` は、もとのリポジトリでコマ割りを足したり直したりしたときに書き出し直して置き換えます。
